# AI 接手文档

后续 AI 请先按顺序阅读：

1. `AI_HANDOFF.md`：项目目标、已完成事项、真实验证结果、当前状态和下一步。
2. `MAP_DOWNLOAD_AND_EXTRACTION.md`：78 张地图清单来源、CDN URL 算法、下载校验和批处理流程。
3. `REPOSITORY_LAYOUT.md`：哪些文件必须保留、哪些内容不得提交、开发版与服务器部署版的区别。

根目录 `map_download_links.txt` 保存了全部 78 张地图场景的精确 CDN URL、XXH64、大小、下载状态和相对保存路径。

此目录不保存凭据，也不依赖之前的聊天记录。文档中的状态以仓库当前文件为准。
