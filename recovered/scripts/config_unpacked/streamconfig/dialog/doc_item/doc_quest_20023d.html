标题：昆班达行踪报告书

制作人：达文斯，阿尼尔摩

1. 昆班达的目的

龙族昆班达是搭乘在格尔克马洛斯要塞坠落的德雷得奇安的德拉坎之一，看上去级别好像不是很高。

他趁德雷得奇安坠落的时候抢走了希埃尔的宝物，避开了龙族和魔族的追踪者，正在逃亡之中。

他为何会违抗格尔克马洛斯的绝对支配者提亚马特的命令，擅自行动，目前还无法确定。

根据目前掌握的情况，他曾经属于与提亚马特敌对的龙族势力。但是昆班达很可能是出于个人目的，而不是受到敌对势力的指使。

在抢走希埃尔的遗物，逃到地下城市之后，他一直是单独行动。从这一点看，他应该是为了个人的目的。

2. 传说中的祭坛

鸢族幸存者们说曾经在受到诅咒的地下城市见到过昆班达。

昆班达可能是想在受到诅咒的地下城市的古代秘密祭坛上，用希埃尔的遗物来进行某种仪式。

根据鸢族协助者提供的情报，在龙族背叛永恒之塔之前，在格尔克马洛斯曾经有一座永恒之塔的神殿。

在神殿中有好几个受到永恒之塔祝福的祭坛，如果昆班达利用了祭坛的力量，不知道会发生什么事情。

但是在大崩溃之后，提亚马特破坏了神殿，永恒之塔的祝福也失去了力量，神秘祭坛也从此不知所踪。

这只是鸢族流传下来的传说，无法确定是否是事实，但可以确定的是昆班达的目的是祭坛。

3. 地下城市的仪式

他好像是想在受到诅咒的地下城市倒塌的古代神殿里找到祭坛，举行某种仪式。

由于昆班达周围被遗物的力量所包围，我们无法靠近或攻击他，只能进行监视和记录。

从以龙骨为首的祭祀工具来看，他好像是想用希埃尔的遗物的力量来复活龙。

永恒之塔毁坏之后，祭坛就失去了力量，他可能是想用希埃尔的遗物中的力量来代替。

但是仪式失败了，昆班达没能让死去的龙复活，此后就失去了踪迹。

4. 今后的行踪

虽然有追踪者在追踪昆班达，但是在援军到来之前被他逃跑了。

追踪者得知的最后一个情报，是昆班达向巴卡巴塔激战地那边逃走了。

我们认为昆班达仍然没有放弃复活龙的计划。

格尔克马洛斯的某个地方应该还有秘密的祭坛，昆班达的下一个目的地，应该就是那里。

从昆班达举行的仪式的规模来看，要准备下一次的仪式，应该需要很长的时间。

必须尽快对以巴卡巴塔激战地为首的格尔克马洛斯全境进行搜索，找到祭坛的位置，攻击昆班达的弱点。
