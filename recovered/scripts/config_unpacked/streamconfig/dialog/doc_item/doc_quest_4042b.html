亲爱的姐姐，萨赫努。

为什么我当初就没听姐姐的话呢？人类终究似乎还是无法和塞伊兰相结合的。纳赫尔古城的人们都反对塞伊兰成为领主夫人，大家都很讨厌我。

我害怕领主会因此不再爱我。所以就把自己的声音给了一个叫塞兹内克的咒术师作为让他把我变成人类的代价。

没想到没过多久，领主很快又爱上了年轻美丽的卡尔蜜雯。明明不久前还口口声声说只爱我一个人的……

随着污染日益严重，城主和卡尔蜜雯丢下我，逃到了阿德玛城寨。

由于不可能把所有的人带进阿德玛城寨，为了挡住蜂拥而去的人群，他们竟然封锁了古城的城门。

我被锁在城里，哪里也去不了。唯一能做的只有思念姐姐，并将装有信的瓶子从铁窗的缝里扔进大海。

剩下的人不是被饿死就是因为污染而被毒死。

现在只剩下我还活着了。死去的那些人变成了僵尸，天天撞击着我的房门。

姐姐，我估计我活不了多久了。要是能在死之前再看一眼姐姐该有多好啊……

好想你，姐姐。
