记录之书

(打开书之后，传来了鸢族萨比努斯的声音。)

我叫萨比努斯。

鸢族是侍奉希埃尔的人。

曾经是和你们一样的亚特雷亚人。

希埃尔主神赐予了我们希埃尔之枪的名字，给了我们任务。

在我们潜入龙界活动的时候，发生了大崩溃。

我们被迫留在了龙界，其中一部分人死了，一部分人幸存了下来。

幸存下来的人以坚强的意志在龙界坚持了下来，最后在英吉斯温定居下来。

在漫长的岁月中，我们经历了无数的考验。

那就是鸢族的原动力……

希埃尔之枪这一光荣的名字已经被人忘却，但我们没有忘记自己的骄傲。

希望天族们能够记住。

我们是希埃尔主神麾下最早的精锐军团。

我们是在龙界生存下来的骄傲的种族。
