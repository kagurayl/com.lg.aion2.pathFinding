约尔姆纳德的体液

分类：动物属

提取方法：“约尔姆纳德”这种动物的体液。托乌云贸易团可以购得。将其犬齿向后按，便能射出毒液。

症状：服用1滴以上的剂量立即死亡。

解毒方法：暂无办法解毒。

乌云贸易团的走私物品之一。由于没有相应的解毒药剂，因此带入天界或在天界流通此毒将会受严厉惩罚。

佩里亚的根

分类：植物属

提取方法：用十年以上的佩里亚之根榨取出的汁液。干燥成粉末状后可使用。

症状：服用一勺以上的剂量时，引发四五天的连续高烧，最后支气管和肺部的变异引发呼吸困难，导致死亡。大量吸食燃烧佩里亚之根所产生的烟气也将导致中毒。

解毒方法：用从孢子囊中提取出来的中和剂与奥黛尔拉一起可解此毒。

格力玛的愤怒

分类：动物属毒与植物属毒的综合体

提取方法：在树汁格力玛的体液中，按7：3的比例加入三尖树的树汁和刺后混合而成。

作用：持续暴露在其中便会中毒。使人产生幻觉或噩梦，引人跌下绝壁或溺水而亡。

解毒方法：饮用长时间熬制的三尖树果实可缓和症状。尚无可以彻底解毒的办法。

欧比斯的诅咒

分类：矿物属

提取方法：将黄玉的粉末、研磨剂粉末、精灵石粉末以及产生于欧比斯的浮游物质的碎片，按1：2：1：0.5的比例混合。将混合粉末用下级精灵水调和后加热萃取，可得此毒。

作用：吸入粉末将引发呼吸器官疾病等多种疾病。症状表现为气喘和积痰，持续吸入将最终伤害肺部而导致死亡。

解毒方法：用上级精灵水清洗口腔和呼吸器官，将减缓症状。严重中毒时暂无解方法。
