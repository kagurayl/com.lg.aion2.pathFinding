泰亚的故事

红色雷杰军团是特里尼埃尔主神麾下的军团。虽说跟随特里尼埃尔主神的大多为杀星和弓星，但红色雷杰军团的军团长比尔凯却是守护星。

为什么特里尼埃尔主神的军团里会让守护星做军团长，我也不清楚。只知道比尔凯是个能力出色的军团长兼战士。

我记得军团兵里还有个三兄弟。希尔赫、巴尔屈，还有贝尔特，这三兄弟全都是杀星。这三个人都属于高傲狂放型的，经常会出言不逊，但对于比尔凯军团长却是誓死效忠的。

反正军团的凝聚力和组织力相当强，只要军团长比尔凯出马，其他军团兵都有条不紊地按照部署行动，很快就能压制住龙族的进攻。据说在他们之前与之后，就再也没有过战斗力比他们更强的军团了。

比尔凯军团长为什么每次都能大无畏地身先士卒……啊……头……我的头……

对不起……就到这里吧……
