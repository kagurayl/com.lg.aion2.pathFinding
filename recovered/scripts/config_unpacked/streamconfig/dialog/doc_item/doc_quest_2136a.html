伊斯夏尔肯传说童话集

第9卷 金斧子，银斧子

很久很久以前，有个小岛上生活着一个小偷。

这个小偷是个善良的小偷，经常从贪心的富人那里偷了东西分给穷人。

但是有一天。

小偷在森林里发现了一个插着一把斧头的树根。

“这种地方怎么会插着一把铁斧子...就这样放着的话，人们就不能坐在树根上休息了。”

善良的小偷想要把树根上的铁斧子拔下来，但是斧子插得太深，拔不出来。

“这可插得真牢啊。那我来加点力气？一，二，三！”

可能是拔斧子的时候力气用得太大了，斧子从手里滑了出去。

铁斧子在空中划了条抛物线，钓到了旁边塔鲁的泉水里。

“啊，怎么办呢？斧子的主人一定会来找的...”

小偷很着急，不知道该怎么办才好。

他想能不能把斧子捞起来，但是他看了看泉水，泉水深不见底。

“这可怎么办呢？尽出来闯祸了。”

善良的小偷趴在塔鲁的泉水旁边，哭了起来。

哭着哭着，泉水里突然冒出了一股气泡，“嘭”的一声，一个年老的守护者出现了。

那个守护者擦了擦额头，不容分说地叫了起来。

“你是谁啊？是谁把斧子扔到了泉水里！”

小偷被突然出现的守护者吓了一跳。他没有回答，呆呆地站在那里。

“是你扔的斧子吗？我正在冥想，因为你差点没把头给砸破。”

守护者大发雷霆。小偷颤抖着回答道：

“对，对不起，守护者大人。实际上是...树根上插着一把斧子...我只不过为别人着想，想把它拔下来罢了。”

善良的小偷结结巴巴地说明了情况。

知道他不是故意的，守护者的火气也消了。

“知道了。既然你说不是故意的，我就原谅你一次。你赶紧回去吧。”

年老的守护者刚想要回到水里。这时，小偷说话了。

“对不起，守护者大人！您能不能把我之前掉下去的斧子还给我？”

守护者虽然觉得很好笑，但是小偷说必须把别人的斧子找回来，他不得以回到泉水中去找斧子去了。

过了好一会儿，年老的守护者拿着一把金斧子出现了。

“这把金斧子是你掉的吗？”

金斧子看起来很贵，但是小偷很正直。

“不是的。我掉的不是金斧子。”

“也是，世界上有哪个人类会用金斧子砍树啊。知道了。我再去找找。”

年老的守护者再次回到了泉水中。这一次他带着银斧子出现了。

“那么这把银斧子是你掉的吗？”

“这个也不是我掉的。”

听了盗贼的回答，守护者皱了皱眉头，又回到了泉水里。

过了好一会儿，守护者带着铁斧子出现了。

“那么这把铁斧子是你掉的吗？”

看到生了锈的铁斧子，小偷点了点头。

“是的，没错。这是我掉的。”

年老的守护者听了小偷的回答叹了口气。

“最近这种世道居然还有你这种不识抬举的人...”

“要想在这个世界上生活，就得能察言观色，知道为自己的利益着想。”

年老的守护者说了小偷一通，然后突然把三把斧子全都给了小偷。

“拿着。这是对你的正直的报答。”

留下一头雾水的小偷钻进泉水消失了。

只剩下一个人的小偷看着泉水，深深地行了个礼，连声道谢。

回到村里之后，小偷把金斧子和银斧子卖了，赚了很多钱。

并且用那些钱成立了新的盗贼团，继续教训那些贪心的富人，帮助贫穷的人们。

当然他还娶了个漂亮的妻子，生了个漂亮的孩子。

请经常帮助周围的人。也许那个小偷就在你的身边。
