第2章：梅斯兰泰达

在第1章中我们提到了亚人种对龙族的崇拜历来已久，有推测认为这种崇拜早在人类和守护者出现于亚特雷亚之前就已经系统化了。

亚人种中，克拉尔势力对龙族的崇拜体系最为完善，一直持续至今。

红龙祭坛是信奉五龙帝中的梅斯兰泰达的克拉尔一族的祭坛，他们的族长库拉卡相信自己是由梅斯兰泰达委任的。

他们的祭祀仪式是在非常森严的戒备状态下形成的。关于祭祀仪式的详细内容和过程，人类只有一些口头流传的不明确的传言，具体情况尚无法考证。

就像大家都能猜到的一样，也就仅仅局限于在巨大的石头祭坛上献上祭品然后举行仪式等这些信息了。

梅斯兰泰达是五龙帝中仅次于普雷奇温的排名第2的龙帝。被称为红龙的梅斯兰泰达主管死亡和恐怖。

龙族对于权力有一种天生的攻击性欲望。从他们想支配亚特雷亚的意图中就可见一斑。

在龙界那边蠢蠢欲动，觊觎亚特雷亚的龙帝们正如我们平时所想象的那般凶狠可怕。

侍奉梅斯兰泰达的克拉尔族统治着布洛尼部落，并要求布洛尼们也信奉梅斯兰泰达。

通过这一举措，克拉尔得以加强他们对布洛尼的统治，也为亚人种内部的从属关系披上了合理化的外衣。

红龙神的祝福可以从强调克拉尔能力的亚人种主义和强调红龙神能力的能力主义两个层面来理解。

布洛尼仅仅服从于克拉尔的统治，但并不参加红龙祭坛的祭祀活动。

那么克拉尔究竟是如何对梅斯兰泰达进行祭祀的呢？

首先，我们推定红龙祭坛的祭祀活动一直持续到龙族被赶出结界外为止。

虽然最近在托尔巴斯森林附近出现了克拉尔的活动迹象，但很难断定他们就是为了从事祭祀活动而来的。

当龙帝们还没有被赶到结界以外时，红龙祭坛曾经举行过大型的祭祀活动。因此，红龙祭坛直到现在依然被克拉尔奉做圣地。

亚特雷亚已经找不到五龙帝的踪影，克拉尔活动也受到了人类的限制。那么现在的红龙祭坛还具有怎样的意义呢？

红龙祭坛现在也只能代表克拉尔统治布洛尼的正当性，并具有强化克拉尔内部团结的意义了。
