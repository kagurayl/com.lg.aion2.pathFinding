记录之书

(打开书之后，传来了鸢族萨比努斯的声音。)

我叫萨比努斯。

鸢族是侍奉希埃尔的人。

曾经是和你们一样的亚特雷亚人。

希埃尔主神赐予了我们希埃尔之枪的名字，给了我们任务。

在我们潜入龙界活动的时候，发生了大崩溃。

我们被迫留在了龙界，其中一部分人死了，一部分人幸存了下来。

幸存下来的人以坚强的意志在龙界坚持了下来，最后在英吉斯温定居下来。

在漫长的岁月中，我们经历了无数的考验。

那就是鸢族的原动力……

希埃尔之枪这一光荣的名字已经被人忘却，但我们没有忘记自己的骄傲。

希望天族们能够记住。

我们是希埃尔主神麾下最早的精锐军团。

我们是在龙界生存下来的骄傲的种族。

我叫盖尔伦。

天族！

在我们与龙族和孤独战斗的时候，你们失去了亚特雷亚。

在我们以希埃尔之枪这一光荣的名字来到龙界战斗的时候，希埃尔主神在结界内。

我们一边等待希埃尔，一边和龙族战斗，一部分人幸存了下来，一部分人牺牲了。

那些悲惨地战死，却仍然在为亚特雷亚的未来担心的灵魂们！

如果不是有我们在和龙族战斗，应该会有更多的龙族进入结界。

为了守护亚特雷亚，我们拼尽了全力。

天族！

你们必须记住，在天界和魔界出现之前，人类就已经存在了。

为你们自相残杀而感到悲伤的，只有我们鸢族。

你们难道没有看到吗？古老的亚特雷亚的眼泪。

我们在英吉斯温生存下来的时候，亚特雷亚变成了古老的传说，逐渐被人们忘却。

你们必须记住，无数的鸢族曾经为了保护亚特雷亚而死去。
