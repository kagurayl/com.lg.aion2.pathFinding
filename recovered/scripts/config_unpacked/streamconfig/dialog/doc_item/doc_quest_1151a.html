OO月OO日

埃尔迪奥抱怨说南瓜没有了。

吵着要做什么新式料理，结果什么都还没开始做呢，就要放弃了。

早上收到马诺斯大哥寄来的信。似乎大哥还是不相信邮政系统，拜托加诺顺路带了过来。

信中提到他最近身体不太舒服，行动不方便。我回信说一定会带些有益身体健康的草药去看他的。

OO月OO日

从昨天开始，农场周围就总有些鬼鬼祟祟的家伙们。

是想偷粮食的家伙吗？

无论如何得赶紧去要塞看看马诺斯大哥，然后拜托斯帕塔洛斯大人派些守卫来。

早晨早点出发的话，应该能赶在天黑前回来。

OO月OO日

被强盗和杂役拘禁起来已经四天了。

那帮家伙觊觎的居然不是粮食而是整个农场！

真是后悔自己当时没早点发现他们的图谋。

我写过信给马诺斯大哥说要去看他，他会不会见我这么久都没去就派人过来呢？这是我现在唯一的希望了。

OO月OO日

经常听到这帮家伙提到“雷帕尔”这个名字。

什么“雷帕尔大人”估计应该是他们的头目吧。

贝尔特伦要塞那边还没有派人过来。

难道大哥没发现我这边出事了吗...

OO月OO日

这下完蛋了。

那帮家伙最终找到了地契。

有了地契，他们显然就没有必要继续留着我这个活口了。

刚才他们聚在一起唧唧喳喳地，估计就是在讨论怎么干掉我吧？

马诺斯大哥到现在都还没发觉我出事了吗？

现在，一切都完了...
