- 阿尔特盖德战况报告书 -

发信人：阿尔特盖德要塞队长苏埃伦

收信人：伏魔殿毕达尔总司令官大人

我就任阿尔特盖德要塞的队长之后，为了击退亚人种和恢复领土，进行了持续的作战。

现在取得了可喜的成果，特此向毕达尔总司令官大人报告阿尔特盖德地区的战况。

战斗准备和各战斗相关的详细情况在以后的正式报告中提交。

1. 对亚人种战斗准备

- 重建因派图西姆，作为对抗拉卡恩的前线基地

- 讨伐姆姆族，阻止其提炼奥黛拉

- 怀柔对魔族有好的黑脚势力

- 通过重组执政官部队，有效获取情报和树立攻击态势

2. 对亚人种战斗结果

- 讨伐姆姆族耕作地，扩张了魔族的领土

- 消灭了精锐咒术师，削弱了黑脚的战力

- 消灭了精锐探索兵，弱化了亚人种的警戒态势

- 消灭族长库姆巴伦的手下

根据我的战术，执政官和派遣到要塞的守护者配置合理，获得了以上战果。

递交本报告的人士在战斗中发挥了重要作用的守护者，您一定要看一眼。

相信您对于弱化黑脚部族的势力，除掉库姆巴伦的战绩会很高兴。

为了伏魔殿的光荣！
