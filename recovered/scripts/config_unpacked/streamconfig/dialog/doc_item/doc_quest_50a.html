序言

我一直不停地问自己，对于红龙祭坛的研究在人类历史研究上到底具有怎样的意义。

只有了解了充斥着欲望与冲突的亚特雷亚历史，在我们所处的结界领域内，才能够实现使神圣性得以自觉的历史性飞跃。

第1章：龙族的阶级构造

关于亚特雷亚最初的主人——龙族的诞生背景，现在还无从考据。只知道龙族出现于人类之前，从一开始就拥有足以产生宗教膜拜的强大力量。

在探究龙族是如何对亚人种产生宗教方面的影响，并将亚人种牢牢控制在自己的影响力之下等等问题之前，我们在第1章中先来了解一下龙族的权力结构。

第1章：龙族的阶级构造

龙族权力构造的最上层由普雷奇温、梅斯兰泰达、艾莱休奇卡、布里特拉、提亚马特等五龙帝组成。

被称为龙的一般龙族和德拉科纳、纳加、蜥蜴人等则位居其次。

五龙帝的势力现在还无法到达结界附近，但有些守护者认为他们正在积蓄力量，企图穿过欧比斯，入侵亚特雷亚。

当然也有一些人猜测极乐世界和伏魔殿的军事组织为了防御魔族的攻击而活动频繁正是因为获得了一些重量级的情报，但却没向一般人类公开。但是这些猜测至今并没有可靠的证据。

现在只知道在大崩溃的混乱中，五龙帝去了结界以外的地方。

龙，是亚特雷亚原本的主人——德拉科纳的觉醒体，虽然没有五龙帝那么大的威力，但龙族本身的强力却被唤醒，拥有巨大而惊人的力量。

占龙族最大比重的德拉科纳一族是龙的前身，保持着龙族原有的面貌。他们的相关历史将在下一章节中进行论述。

纳加和蜥蜴人是一些德拉科纳的变异。

大崩溃后，奥德的流动处于一种剧烈不稳定的状态。欧比斯等奇异的空间就是在当时那种奥德的剧烈冲击下形成的。

一部分德拉科纳也在当时发生了形体变异，成为了纳加；另一部分德拉科纳则丧失了龙族的特点，退化成了蜥蜴人。

龙族对权力结构是相当敏感和重视的。五龙帝和觉醒了的龙族位于权力的上层，其余龙族都处于被统治的地位。当龙族统治亚特雷亚的时候，亚人种也被纳入了他们的统治体系，甚至对龙族还产生了宗教崇拜和信仰。

龙族的统治在囊括了亚人种后，形成了一个森严的金字塔结构。

在这种金字塔型的统治结构下，许多礼仪仪式出现了，最终在亚特雷亚的各地出现了大大小小许多祭坛。

其中，信奉红龙，即梅斯兰泰达的一部分亚人种修建了红龙祭坛。
