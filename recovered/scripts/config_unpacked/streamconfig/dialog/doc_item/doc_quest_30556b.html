这项工作毕竟关系到很多人的生命，以及鸢族的未来……想想都觉得肩头很沉。

OO月 OO日

几天后应该就可以正式开始军事训练和武器的锻造。

愿希埃尔主神保佑一切都顺利。

发生这种事情，让我想到了很多。

用一个士兵的生命去换取大义，值得吗？

所谓大义，所谓鸢族的未来，真的就比一个人的生命更重要吗？
