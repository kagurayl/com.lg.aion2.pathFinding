不久前，我们从代理人大人那里听到了好消息。

派遣到前哨基地的守卫们比原先计划的更快地击败了敌人。

此外，听说幻想之光军团的士兵们发挥了巨大的作用。

我们进攻提亚玛兰塔的计划也因此可以提前，代理人大人特地对大家表示感谢。

啊，你们也许不知道。

听到这个消息之后，我是多么激动。

你们代表幻想之光军团在前线奋勇作战，我为你们感到骄傲。

但是我不知道该怎么表扬你们……

我在这方面一向不得要领，我想用我知道的一首诗来表达。

“持续了几天的战斗

穿透无尽的火焰和黑烟

远处泛白的黎明的天空

当胜利的号角打破静寂的时候

坚定的眼神和整齐的队伍

守卫们再次站了起来。

啊，这个瞬间！

年老的守卫和年轻的守卫

使命感在所有人的心中回响。”

不要忘了，不管我们身在何地，凯西内尔主神都永远和我们在一起。

特此表扬，

幻想之光军团长贝尔塞蒂
