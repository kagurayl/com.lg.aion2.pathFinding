-阿希尔澜号航海日志：第一天-

遵从头目的命令，开始了寻找黑珍珠的航程。

他说必须要去伊斯夏尔肯，一个从来没有去过的地方。

我们为航程准备了40天的食物和水，并准备了小船。

-阿希尔澜号航海日志: 第10天-

听到去寻找黑珍珠之后突然陷入忧郁的诺班，还是那个样子。

问他是为什么，他说传说黑珍珠虽然能够改变命运，但是却会受到诅咒，从开始寻找黑珍珠的那一刻起就会开始遭受苦难。

虽然我劝他不要相信迷信，但是诺班还是嘀嘀咕咕地说不吉利，把船上的气氛搞得很低沉。

-阿希尔澜号航海日志：第15天-

舵出了故障。由于没有准备部件，现在正在拿木头重新做。

诺班到处和人说诅咒开始了，其他的船员对此都很不满。

航行的距离要比计划的短，我有点担心。如果有合适的地方，必须停靠之后补充水和食物。

- 阿希尔澜号航海日志：第25天-

刮了3天的风暴。船进了水，粮食箱子被水泡湿了。

头目的心情不太好。我怕诺班惹头目发火，让他呆在船舱里不要出来。

越来越多的船员去向诺班打听传说的内容。真想找个岛把诺班扔在上面。

- 阿希尔澜号航海日志：第45天-

可能是因为吃了被海水泡过的粮食，船上的很多人都开始腹泻。

年轻的船员们还能坚持，年纪大一点的船员只能躺在床上。

远远地看见了港口，傍晚时分应该可以到达。补充好粮食和水的话，问题就应该可以解决。

可能是因为太难受，诺班不再说话。真是太好了。

- 阿希尔澜号航海日志：第60天-

可能是因为上次修理的舵有问题。还是没能发现伊斯夏尔肯岛。

诺班发烧了，一直在嘟哝黑珍珠的诅咒。不知道是不是诅咒，情况再这样持续下去的话大家可能都会死掉。

不知道头目是从哪里听说了黑珍珠的事情而决定要去寻找的。因为有这个传说，所以也不可能卖上什么好价钱。

最近我的心里真不是滋味。头一次后悔当了海盗。

- 阿希尔澜号航海日志：第75天-

我们进行了第五次努力，但是还是没能发现陆地。

粮食快吃光了。船员们也正在以相同的速度死亡，所以可能比想象的可以坚持更长的时间。

不知道传说是不是真的，还是因为诺班的乌鸦嘴，这次航行真的像是受了诅咒的航行。

真能找到黑珍珠的话，我不要改变未来，而是要改变过去。就算让我把头目给痛揍一顿，也不能让他开始这趟航程。
