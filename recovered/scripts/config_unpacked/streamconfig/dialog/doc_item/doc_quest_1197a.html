- 提炼原理

要提高奥德石的浓度，必须将其转换为液体状态，滤掉杂质。

在铁坩埚中将奥德石和比尔克树汁的浓缩液一起煮沸，这样能够降低奥德石的熔点。过一段时间就添加一些比尔克树汁的浓缩液，直到奥德石完全熔解为止。

将奥德石溶液盛放在用安杰丽卡的茎编织成的容器内，杂质便能附着在安杰丽卡的茎条上，从而提升奥德石的纯度。

- 准备材料

比尔克树汁浓缩液：加热比尔克树汁，直至3桶树汁浓缩成1桶时为止。关键在于不能将树汁完全煮沸，而只能用小火一点点熬制浓缩。

安杰丽卡的容器：必须用3年以上的安杰丽卡，将粗厚的茎条撕细，在沸水中焯一下，再拉扯成细丝。用细丝编织成容器。待炒过安杰丽卡茎条的水冷却后，取出沉淀在底层的粘液，涂抹在编好的容器表面，即可。
