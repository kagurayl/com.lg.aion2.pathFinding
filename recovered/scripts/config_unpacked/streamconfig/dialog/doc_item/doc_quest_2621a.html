致普莱尔哥哥

不好意思，回信晚了点。

看了哥哥的来信，知道大家现在都过得很好，我就放心了。

我最近过得也还不错。

不过，同寒冷作斗争可不是一件容易的事情。

上次哥哥寄给我的棉袄，可暖和了。总算是帮了我的大忙。每次穿上棉袄，我都会忍不住想起哥哥和家人。

相信哥哥也知道吧，贝鲁斯兰的状况很严峻。

哥哥肯定想像不到的，这里的情况比外面传说的要危急百倍。

我必须随时保持高度警惕，万事都得小心翼翼。

好在一起竞争的都是些直爽人士，我的能力也得到了他们的肯定。

但按现在的情形来看，我可能没办法完成哥哥托付的事情了。

拉盖乌姆矿产在离这里很远的地方，我作为百夫长又不好为了这事而擅离职守。

我觉得还是哥哥直接找术古买比较好。

外面有人叫我了，信就只能写到这里了。

下次有时间了，我再给哥哥写信。

希望哥哥工作顺利，常联系哦。

普雷伊亚，写于贝鲁斯兰...

附：

对了！下次哥哥写信过来，最好找个熟人带过来吧。

术古快递的家伙们拖拖拉拉地，害得我很晚才收到信。
