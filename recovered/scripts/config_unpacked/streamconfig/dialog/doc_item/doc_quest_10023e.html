00月00日

(用复杂的字体写着。)

终于揭开了老师的书中的组合原理！

这样的话，距离复活巨神兵就又近了一步。

但并不是解开公式就可以了……

最近经常很焦虑。

00月00日

来到英吉斯温寻找巨神兵的碎片已经很长时间了。

但是还没有找到和巨神兵的动力源有关的线索。

泰奥勃莫斯大人在咽气之前说，失败的原因是动力源……

虽然我一直想找到它，完成老师的遗志，但是却没有找到任何线索，就像是在追踪一个没有形体的影子一样。真让人郁闷。

但是老师应该不会搞错。

没能找到巨神兵的动力源，只不过是因为我太愚蠢和懦弱罢了。

00月00日

过去我们在没有解开巨神兵的所有疑问的情况下，就创造了巨神兵。

因为那时情况紧急，所以没有办法。结果我们不得不承受巨人兵在普雷奇温的火焰中倒下的痛苦。

但是我们不会再犯同样的错误。

我一定要找到和巨神兵相配的动力源，让他恢复原貌。

00月00日

在英吉斯温东部搜索的时候，发现了一群奇怪的人。

他们使用的语言和长相都和我很相似，他们崇拜龙。

追随龙的人类和守护者……好像曾经听老师提到过。过去曾经有过那样的背叛者。

虽然其他的记不清了，但老师的话我还是记得很清楚。

人类的意志没有想象的那么强，而我们的敌人也是非常可怕的存在。

但是这样的理由并不能让我原谅他们的背叛。

而且他们把自己的行动看作是合理的，并且用恶劣的手段给自己的同族带来了痛苦。

00月00日

老师说所有生命的原理都是源自永恒之塔的意志。

唉，有时我也难免会抱怨，老师为什么要说这种谜一般的话。

如果能告诉我是用什么矿物制作的生命，需要几个石头、几块奥德精髓……等等具体的东西，那该多好……

对了！我在监视他们的动态的时候发现了一个奇怪的现象。

他们向神殿运送了大量的十字镐和铲子，到了黄昏的时候，所有的人都累得气喘吁吁的出来。

这样一直持续了很多天，里面一定发生了什么事。

要是能靠近观察一下……说不定能发现些什么。

00月00日

好不容易杀死了一个龙崇拜者，抢到了他的衣服。

虽然大概练习了一下他们说话的口音，不过他们都忙着干活，不用担心会被发现。

不知道明天早上能不能混进地下神殿。

00月00日

有了惊人的发现！

据龙信徒的头目说，如果找不到巨神兵的部件，大家就别想活着出去！

这是什么意思啊？

虽然不知道是什么意思，但他们一定是在寻找巨神兵。

看来我得找个龙信徒套套口风。

那样的话，应该就能知道更多与巨神兵的动力源有关的情况了。

00月00日

那个东西，就在这里！

老师说的都是真的。

而且还有传说中的巨人……

必须把那个东西抢到手。但是应该怎么办呢……？

现在必须打起十二分的精神才行。

报答老师的牺牲，亚特雷亚的命运……全都靠这个了。

00月00日

不好了。

必须尽快离开这里……
