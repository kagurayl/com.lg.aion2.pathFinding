希凯雅大人亲启

愿尤斯迪埃主神的恩宠与你同在！

很抱歉出现了有损名誉的事件，不过您还记得梅斯兰泰达之血吗？

那是备受瞩目的两位制毒专家，为了战胜魔族而受命研制而成的剧毒，然而却因为毒性过于猛烈而无法使用。

我记得两位专家最后也因为身中带有高传染性的剧毒被拒绝返回极乐世界。虽然尤斯迪埃主神后来制作出了解毒剂，但那已是很久以后的事情了。

我所派出去的守护者带回了梅斯兰泰达之血，并请求获得解毒剂。

他说梅斯兰泰达之血正在不断污染着贝尔特伦。听了他的报告，我觉得事态已经相当严重了。

如果还有尤斯迪埃的眼泪剩下，请赐予他一些吧。也许这是拯救贝尔特伦契机也说不定呢。

真希望悲剧能够就此结束。
