我被监禁了。

就在我以为自己就要在平淡中度过余生的时候，最小的弟弟马弩阿出现了，并将我监禁了起来。

已经有好久都没见过马弩阿了，这段时间里他变了不少。

他和他的朋友们说是要在我的农场里从事重要的工作。

我整理了自己混乱的思绪。

两天前，自己在空荡荡的房子里吃午饭的时候，突然想起了一些往事。

想起了和父亲母亲，马诺斯哥哥和马弩阿一起开开心心生活的日子。

就在这时，说曹操曹操到，马弩阿推门走了进来。

马弩阿变了许多。

跟以前简直判若两人，瘦削的脸上浮现出隐隐的杀气。

不过，我还是很高兴能够再次见到他。马弩阿的表情却很冷淡。不一会儿，有三个流浪汉样子的人也推门进来了。

马弩阿告诉我那些人是他的朋友。

他们需要这个农场。

马弩阿希望我能够深明大义，将农场贡献出来。

我怎么能把父亲传下来的农场交给那些家伙呢？

我刚表示出反对，那些人就开始对我拳打脚踢。而马弩阿只是在一旁默默看着。

就这样，我被监禁在了这里。

马弩阿亲自把我监禁起来以后，径直走向存放谷物的仓库。很快就听见了锁被撬开的声音。

第二天，马弩阿拿了些吃的来。

我求他放了我，但他脸上别说是兄弟之情了，就连人类应有的感情都看不出来一丝一毫。

监禁后的第3天

我看见他们在里屋开会。

他们不断地说着亵渎神圣的话语。

我听到他们提到了结界守护塔，但却没听清具体是怎么回事。

不知道他们打算把我监禁到什么时候。

监禁后第7天

马弩阿一般每天都会来送一趟食物，但昨天和今天都没有来。

我最近总是回想起父亲。

父亲没有看到马弩阿和我现在的样子就撒手人寰也许是种幸运，但说不定正因为父亲的离世，马弩阿才会变成现在的这个样子？

监禁后的第8天

马弩阿今天也没有来。肚子饿死了。

这样继续把我监禁下去，我肯定会饿死的。不，他们会来直接杀死我也说不定。

仁慈的守护者啊，乡邻乡里们啊，为什么还不来解救我呢？

监禁后第10天

已经足足五天什么都没吃了。

嗓子好渴。

听到里屋有很喧闹的样子，大概有十个人？二十个人？

监禁后第11天

也许我的生命快到尽头了。

脑袋晕沉沉的，意识也开始模糊了。

嗓子好渴...
