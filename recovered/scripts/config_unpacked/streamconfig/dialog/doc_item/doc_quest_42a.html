奎德罗亲启

事态紧急，我就长话短说了。

你要理解为父现在写这封信时的不安和惶恐，仔仔细细地读这封信里的每一句话。

你走后的第三天，奥德的光芒逐渐暗淡，你叔叔马弩阿来找我。

他带来了三个据说是他同事的举止诡异的人。

他们经常说一些奇怪的话，什么亚特雷亚的秩序即将为革命所掌控之类的。

看样子，你叔叔和那几个“同事”已经认识很久了。

他们说着许多令人不解的话，在家里吃喝喧闹，还说要村子的圣物——净化水晶。

他们说圣物摆在神殿里不过是守护者们傲慢的象征罢了。

为父我对此当然是不能苟同，但那些人不断地怂恿并威胁我。

现在想想，你叔叔当时也站在他们那边。

你的叔叔已经不再是以前我们认识的那个人了。

而且，你叔叔显然是知道神官的钥匙保存在我这里的。

没办法，我只好把净化水晶偷了出来，交给了他们。

他们极力劝我和他们一起去他们的据点。

不过，他们似乎突然接到了什么号令，于是就迅速离开了。

你叔叔走的时候，丢下了一句话。他说失踪的巴尔波亚早就已经死掉了。

奎德罗，为父现在敢保证，巴尔波亚的死肯定和你叔叔有关系。

不过，这种我们也无能为力的事情，现在先放一边吧。

我给你写信是为了神殿的圣物。

那个东西既然失踪了，村子里肯定要组织调查的，到时候肯定会发现我的。

我要说是被亲戚给要挟的，肯定没人会相信我。

最近，我天天担心得连觉都睡不着，饭都吃不香。

一定要在守护者们知道神殿的圣物失踪之前，离开这个村子。

- 父亲
