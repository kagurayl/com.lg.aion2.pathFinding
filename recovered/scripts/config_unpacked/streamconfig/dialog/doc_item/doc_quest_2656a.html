说实话，我现在也就只剩下一层皮了。我心里只有一个想法，那就是一定要向杀死马伊内的家伙们报仇。

让我放弃报仇，还不如现在就将我杀死。让我回魔界也是一样。

我只想活在对马伊内的思念中。消灭天族守护者，让他们变成不死族，才是我思念马伊内最好的方式。

贝托尼，我很感激你的心意，但请不要再管我了。

要我忘记马伊内，那活着跟死了就没什么区别了。我不管你怎么看我，反正现在这种生活方式，对我而言才是最幸福的。

忘记我这个被爱情迷住双眼的愚蠢朋友吧。
