父亲大人启

上次您送来的烤德布里蛋很好吃。

实在是太好吃了，我还是头一次吃到那么好吃的东西。

如果不是遇到了父亲，我可能一辈子都不会吃到这种珍味吧？

这样一想，我的心里就好受多了。

因此，我也不想故意为难您了。

不管您喜欢也好讨厌也好，我们都是父女关系，不是吗？听说血肉之情是非常珍贵的。

但是约定就是约定，请您把上次答应为我买的东西送过来。

一共是三样东西，首先我需要玉珠。

听说它对健康很有好处，所以我想要一个。

另外我听人说，奥德头带对觉醒好像很有帮助。

虽然这把年纪变成守护者也干不了什么事，但至少永远可以和父亲待在一起了。不是吗？

最后，我这个老女儿为了保养皮肤，需要加布隆那里出售的除皱特效药，请您帮我买一点。

哈尔莫奈 敬上
