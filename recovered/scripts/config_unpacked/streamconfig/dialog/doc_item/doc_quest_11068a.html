- 英吉斯温奇怪气流报告 -

1. 报告书的目的

虽然目前奥德飞行装置运转正常，但缺点是需要人手管理和花费费用。

特别是会消耗大量的奥德，消耗永恒之塔碎片的力量。从长期来看，可能会给英吉斯温的战争造成不利的影响。

因此根据本人在英吉斯温执行任务的过程中发现的情况，我想提出一个新的建议。

2. 英吉斯温的奇怪气流

从大地的裂缝和缝隙中吹出来的充满奥德的气流，我想应该有很多人报告过相关的情况。

据推测，这应该和提亚马特引起的地壳变动有关，这次发现的异常气流应该也是由于这个原因引起的。

异常气流是横贯特定区域的强烈的气流，呈白色带状，可以用肉眼看到。

经确认，顺着气流划桨，可以横穿多个地区，进行大范围的高速移动。

不仅不用消耗奥德和肉体的力量，还可以中途着陆，因此是一种非常高效的移动手段。

3. 确认的地区

’=- 龙泪峡谷

在索泰利亚圣所村北部的龙泪峡谷中发现了大型气流。

经过实地确认，中途不着陆时，可以到达安格利浦废墟。

不仅可以在主要据点圣所村快速移动，还可以在安格利浦废墟地区发生要塞战的时候快速机动地压制敌人。

’=- 堕落地下要塞

在堕落地下要塞上空发现气流通道。

开始于地下要塞上部山坡上的气流，一直穿越到堕落地下要塞的上空。

该气流在讨伐堕落地下要塞的龙崇拜者时将会非常有用。

目前还不知道崇拜者们是否知道气流的存在以及气流的使用方法。

4. 建议

据我所知，除了这两处已查明的场所外，在英吉斯温的各地还有很多类似的气流。

希望凯西内尔之翼研究所和英吉斯温上层尽快确认类似的气流，为天族提供方便。

这种方法，可以节约浪费严重的奥德，在军事方面也非常有用。

此外据我推测，在格尔克马洛斯应该也有和英吉斯温类似的气流。

因此尽快查明格尔克马洛斯的气流，不让敌人知道，是我们必须要做的工作。
