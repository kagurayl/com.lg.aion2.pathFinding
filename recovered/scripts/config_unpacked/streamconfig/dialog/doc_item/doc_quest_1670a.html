OO月OO日

终于到达了因特尔蒂卡。

一开始觉得这里的地形相当复杂，还有许许多多古代城市的遗址遗迹。

今天只是在要塞附近转了转。要塞建在高山上，下山的路相当险峻。

另外，头一次看到浑身毛茸茸的动物。据说叫做长毛雪人，这可是天界任何地方都见不到的。

OO月OO日

普依艾密林真够雄伟壮观的。

除了茂盛的树林，还有非常丰富的动植物和昆虫物种，这里真是名副其实的生态学宝库。

要是这个地方被开发出来，得有多少人会慕名而来啊。

OO月OO日

发现了一个神秘的莲花池。

逛到奇夏尔克拉尔聚居的地方，却被那些家伙们给赶了出来。吓得我没命狂逃。

当时自己已经无路可退了，于是就纵身跳进了池子。没想到浑身突然被一种明亮的光芒给环绕，定神一看，自己居然已经来到了一个截然不同的地方。

不知道这里是什么地方，也不知道还能不能回到莲花池那边。

OO月OO日

我在这块神秘的地方徘徊了许久，看到了奇怪的风景。

海上有三个石头柱子撑起来的岛屿，成三角形状分布。那三个岛之间，似乎还有什么小动物在空中走来走去。

我敢像五主神发誓，我绝对没有眼花。怎么可能在空中行走呢？

难道是那些动物有什么特异功能？还是空中有什么看不见的东西？

OO月OO日

哈哈哈哈，岛屿之间原来是由看不见的桥连接起来的啊。

虽然自己很害怕，但还是壮着胆子迈出了一步，脚下果然感觉到了坚硬的东西！

我仔细转了转宾盖布欧、杰休奇和扎皮埃尔这三个岛屿。

我要是告诉其他的探险家，他们能相信吗？也是，连亲自去过的我都有点不敢相信那是真的。
