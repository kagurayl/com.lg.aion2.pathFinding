汉斯的回忆

龙族为了占领布鲁斯特豪宁，派出了大型军团缁纽基军团。

我们在人数上完全处于劣势，但在特里尼埃尔主神的精锐部队红色雷杰军团的带领下，我们仍然和龙族展开了激烈的战斗。多亏了比尔凯军团长的出色指挥，我们在人少的情况下还能和龙族平分秋色。

不过，随着龙帝布里特拉的亲自出马，战局立刻发生了扭转。在布里特拉所创造的黑暗中，所有人都不寒而栗，失去了战斗的意志。

如果不能重新张开结界，恐怕布鲁斯特豪宁就得拱手让给龙族了。

艾尔文的回忆

布里特拉入侵的时候？那时候真的就只有背水一战了，连人类都加入了战斗。当然啦，人类死了可就没法复生了，所以他们主要是通过间接的支援参加战斗的。

人类主要负责修建防御工事和打造守护者使用的武器。制作大量的箭矢也是个大工程。

我的父母也做了许多工作。父亲那时候几乎从不着家，母亲则为守护者们准备各种食物。

我则负责搬运奥黛尔拉粉末。为了保证守护者战士们不会精力枯竭，耽误战局，我一直不断地从村子里往战场上送奥黛尔拉粉末。

后来，突然有一天，天地一片漆黑，我吓得立刻逃回了村子。再后来的事情我就不太记得了。反正是被吓得魂不守舍了好久。

黑尔穆特的回忆

大家应该都知道抵抗龙族入侵的那场战斗是由红色雷杰军团所领导的。他们是特里尼埃尔主神麾下精锐中的精锐，因此战斗力不是一般人所能想象的。

其中不少守护者都是杀星，所以整体实力不可小觑。不论是地狱纹样破裂，还是特里尼埃尔之匕首，等等这些技能的破坏力都是相当可观的。

龙帝布里特拉亲自参战以后，红色雷杰军团的战斗力也没有被龙帝瓦解。多亏了有治愈星安盖雅杰出的治愈能力，魔族一方才在布里特拉制造出来的黑暗恐怖中稳住了阵脚。

当然他们也不是无敌的。在结界恢复前，为了阻挡住龙族最后的一轮猛攻，红色雷杰军团竭尽全力，并相继陨灭。

要是我们的实力能够再强大一些……至少如果我能够再强一些，也许就不至于需要付出如此大的牺牲了……
