埃拉库斯沙漠侦察报告

1. 莫尔皮诺斯兽群灭绝事件

发生了栖息在埃拉库斯沙漠的莫尔皮诺斯兽群的灭绝事件。

调查结果，此事为球尾蝎兽所为。

正在执行消灭球尾蝎兽的任务。

2. 达尔塔斯村庄的沙漠化

达尔塔斯村庄已经完全沙漠化，变成一片废墟。

村民们都已四处逃难。

一旦发现逃难的村民，将护送至安全地带。

3. 沙漠正在逐渐腐败

一部分沙漠已经腐败，出现了大群的西莫罗格。

正在调查导致沙漠腐败化的原因。

确定原因后将制定对策。

4. 科塞利德攻击居民

最近，发生了原来从不攻击人类的科塞利德攻击人类居民的事件。

调查结果发现是由于慢性子安迪米温而引发的事件。

消灭问题的根源慢性子安迪米温，并下令禁止科塞利德接近居民。

5. 神秘泉的现状

虽然由生命之守护者看守，但大多数的神秘泉却在逐渐枯竭。

如果不能拯救神秘泉，解决埃尔特内境内的沙漠化问题也将雪上加霜。
